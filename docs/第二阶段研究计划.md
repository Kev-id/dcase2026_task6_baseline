# DCASE 2026 Task 6 第二阶段研究计划

日期：2026年10月11日。阶段主题：短片段定位误差拆解与针对性改进。

## 1. 这一阶段要回答什么

第一阶段发现了真实问题，但最初提出的解决办法没有达到目标。第二阶段先回答：模型预测一个短声音时，是找错了位置，还是找到附近却把边界画得太宽？另外，模型可能已经提出了正确片段，只是给它的分数太低，导致它没有排第一。

我们会分别测量位置误差、宽度误差和候选排序的可改善空间，然后选择其中最值得做的一条路线。第二阶段的最低交付是可靠的诊断结果；若诊断支持某条改进方向，再完成一个受控方法实验。方法不提升也必须如实报告。

暂定论文题目：**音频时刻检索中的时长相关定位偏差：误差诊断与改进**。题目和摘要中的“改进”是否保留，取决于最终实验。

## 2. 第一阶段的依据与假设修正

我们使用离线CLAP音频和文本特征，训练QD-DETR定位模型。B1只在CASTELLA训练；B2使用普通Clotho-Moment预训练；M1在合成预训练时用平方根重要性权重增加短样本抽取概率。B2和M1各有两个微调种子，2023与2024。

| 已有证据 | 能得出的结论 | 不能得出的结论 |
|---|---|---|
| 真实训练片段中54.7%短于5秒，合成训练片段仅1.2% | 存在显著时长分布差异 | 差异就是定位错误的原因 |
| B1验证集短片段过宽比例93.1% | 不用合成数据也有偏差 | 偏差仅由预训练造成 |
| B2相对B1的验证集短片段指标改善 | 普通预训练在本次实验中有帮助 | 合成数据只会误导模型 |
| M1测试集短片段指标在两个种子中均下降 | 当前重采样方案未实现预期 | 所有时长感知方法都无效 |

第一阶段最终测试集结果如下，数值为两个微调种子的均值：

| 指标 | B2 | M1 |
|---|---:|---:|
| 整体R1@0.7 | 15.14% | 15.92% |
| 整体mAP | 12.21% | 12.37% |
| <5秒R1@0.5 | 9.22% | 8.00% |
| <5秒R1@0.7 | 3.17% | 2.50% |
| <5秒预测过宽比例 | 86.32% | 86.08% |
| >=20秒R1@0.7 | 22.83% | 27.03% |

因此，第二阶段不再预设“只要增加短样本就会更好”。我们将检验三个假设：

- H1：短片段主要受宽度偏差限制，保持中心不变而修正宽度能够带来较大改善。
- H2：短片段主要受位置偏差限制，只修正宽度仍无法定位目标。
- H3：正确片段已在候选中，主要问题是没有被排在第一位。

H1、H2、H3可以同时成立，实验不是强制三选一。若三种诊断都显示瓶颈，先处理最有可操作性的部分。

## 3. 数据、模型与评估规则

### 3.1 已有材料与需补齐材料

无需重新下载大数据集。必需材料如下：

| 材料 | 用途 | 当前情况 |
|---|---|---|
| CASTELLA train/val/test JSONL | 真值区间、查询、音频ID | 已有 |
| B2/M1两个种子的最佳验证预测 | 必做诊断、同种子配对 | 云端已有，包含候选区间及分数 |
| B2/M1的配置、最佳checkpoint | 复现与生成训练侧预测 | 云端已有 |
| CASTELLA CLAP特征 | 条件改进与复训 | 云端已有 |
| Clotho-Moment标注、M1抽样记录 | 判断短合成样本覆盖性 | 已有 |
| 训练侧独立校准数据的预测 | 拟合校准或排序方法 | 需要按下述规则生成 |
| 原始音频 | 听取定性案例 | 可选，第一轮诊断不需要 |

离线预测JSONL比现有per_query.csv信息更完整：后者只记录Top-1，不能用来判断Top-5/Top-10候选排序问题。所有候选实验必须读取原始预测文件，并记录实际候选数量。

### 3.2 数据划分和测试集使用

先在验证集上完成诊断；改进方法的参数拟合使用训练侧数据。正式训练仍使用既有训练集，checkpoint按同一验证指标选择。所有模型都使用相同分组规则：<5秒、5至10秒、10至20秒、>=20秒。

对于需要拟合的后处理，推荐按音频ID从CASTELLA训练集划出80%训练侧数据和20%校准数据。同一音频的不同查询必须在同一侧。仅在80%上训练的新模型才可把20%称为独立校准集；既有B2已经见过完整训练集，直接用它在这20%上的预测只能称为训练内拟合，不能假装是独立校准。

便宜的固定宽度缩放可以在验证集做小规模探索，明确标注“验证集调参”。若进入正式学习型校准实验，则使用训练侧独立校准方案，并重跑相同数据划分的未校准基线。不要把整个校准流程混用后只报告最高分。

测试集已在第一阶段查看过。第二阶段不再根据测试分组结果选择参数；方案和参数确定后才做一次最终报告。论文中说明测试集曾用于第一阶段分析，最终结果属于同一数据集上的探索性研究；若需要严格未见过的最终验证，应另准备没有查看过结果的带标注数据。本计划不默认新增此类数据。

### 3.3 指标与匹配

主要指标：短于5秒组R1@0.5、R1@0.7；辅助指标：整体R1和mAP、各时长组指标、预测宽度比例、绝对中心误差、起止边界误差。

IoU表示预测区间与真实区间的重合程度；R1@0.7表示最高分候选的IoU至少达到0.7的查询比例。正的宽度误差表示预测过宽，负值表示过窄。

一条查询可包含多个真实区间，甚至分属多个时长组，因此同一查询可在多个组出现。组计数不能相加当作独立查询，也不能简单加权还原整体R1。

已有脚本用最大IoU选择匹配真值。若所有IoU为0，这种匹配会在多个真值中任意选择第一项，使中心与宽度误差失去稳定意义。第二阶段将同时保存：

1. 官方R1口径：预测与所有合格真值的最大IoU。
2. 几何诊断匹配：最大IoU；并列时按中心距离最小，再按区间起点排序。
3. 敏感性检查：只在存在重叠的查询中分析宽度；在全部查询中另用最近中心匹配检查结论。

中心误差同时报告秒数和相对真值宽度的误差，避免短目标和长目标难度比较失真。不能仅凭“宽度接近真值”就称定位正确。

## 4. 必做实验：先诊断，不重新训练

### D0：复核统计与建立逐查询诊断表

目的：确保后面的结论来自同一批查询和正确匹配。

对B2/M1两个seed的验证集预测生成逐查询表，记录候选排名、分数、区间、真值数量、分组归属、重叠情况、中心距离和宽度比例。检查qid完整性、重复查询、区间合法性、排序方式和候选数量。

产物：统一诊断CSV、元数据和校验摘要。使用CPU即可，约半天内完成实现与核对。

预期及解释：若新匹配规则改变了“宽度误差”的大小，需修正此前描述；R1结果应与官方评估一致。不能为了保留原先结论而沿用不稳定匹配。

### D1：短片段错误类型与条件分析

问题：预测是否至少找到了声音附近？

统计Top-1中心是否落在任一真实区间内、与任一真实区间是否有重叠、中心距最近真值中心的距离，以及宽度比。按固定顺序分类，避免重叠计数：

- 已正确：最大IoU>=0.7。
- 中心在目标内但IoU不足：可能存在明显宽度或边界问题。
- 有重叠但中心在目标外：位置与边界可能共同出错。
- 无重叠：位置或候选选择问题更突出。

这里的类别是几何描述，并不是已经确定的因果归因。特别宽的预测也可能碰巧覆盖真值。

可能现象：

| 现象 | 可以支持的判断 |
|---|---|
| 大量失败预测中心在真值内，且宽度明显偏大 | 值得继续检验宽度校准 |
| 大量预测完全无重叠，中心相距很远 | 单纯缩短片段很难解决问题 |
| 有重叠但中心偏移与宽度误差同时较大 | 需要联合处理边界，不能只看宽度 |

产物：错误类型堆叠图、中心误差与宽度比例散点图、分组计数。CPU数秒至数分钟；实现和人工核对约半天。

### D2：真实中心与真实宽度替换诊断

问题：如果某一部分完全正确，模型最多能从这部分修正中受益多少？这属于使用真实答案的诊断，不能作为模型性能或可部署方法报告。

将预测写成中心c、宽度w，对每个合格真值中心c*、宽度w*分别构造：

| 条件 | 中心 | 宽度 | 判断用途 |
|---|---|---|---|
| 原始预测 | c | w | 对照 |
| 真实中心替换 | c* | w | 位置修正的条件空间 |
| 真实宽度替换 | c | w* | 宽度修正的条件空间 |
| 两者替换 | c* | w* | 实现校验，合法真值应得到IoU=1 |

为避免任意挑选真值，对每个真值都计算替换结果，再按预先固定规则汇总最大IoU。这会使用标签进行理想选择，可能高估实际方法能实现的改善。另提供固定诊断匹配真值下的替换结果，作为敏感性检查。

使用与实际预测相同的裁剪和1秒舍入，再额外保留连续时间版诊断。单因素替换有时会降低IoU，因此报告原始、替换后的分数与升降查询数；不要假定每次替换必然改善。可选保留“原始或替换择优”的理想分数，但必须单独标明其更强的标签依赖。

可能现象：真实宽度替换提升很大，支持H1；真实中心替换提升明显更大，支持H2；二者分别提升有限但共同替换效果很大，说明存在联合错误。不要把两种提升直接相加当作误差占比。

产物：原始/中心替换/宽度替换的分组对比图和逐查询变化。CPU运行，预计实现与检查半天。

### D3：Top-k候选覆盖与排序诊断

问题：正确片段是不是存在，只是没有排第一？

计算K=1、3、5、10时，前K候选与真值的最大IoU是否达到0.5或0.7。若实际候选少于K，使用全部已有候选并记录数量，不能声称考察了未生成的候选。比较Top-1和Top-k理想选择的差距，同时查看候选是否只是重复的相似区间。

可能现象：Top-5远高于Top-1，支持研究候选排序；Top-10仍然很低，说明候选生成本身不足，重排难以补救；正确候选存在但只有很宽区间，仍需边界改进。

产物：分时长Top-k覆盖曲线、正确候选排名分布。它是理想选择的诊断，不等于真实重排模型的成绩。不能通过真实IoU直接给候选排序后报告成方法结果。

### D4：时间分辨率与定性案例检查

问题：短片段的错误是否与1秒舍入或特征时间分辨率有关？

检查特征帧数、音频长度和模型使用的clip_length，记录实际时间步长；分析标注中1秒、2秒、3秒、4秒目标的表现。比较舍入前和舍入后预测，保持模型权重不变。舍入前预测需从checkpoint重新推理并另存，不能从已舍入JSONL反推出精细边界。

增加“真值自身经相同舍入”的参考，量化舍入可能引入的几何损失。这个参考不能被称为整个模型的信息论上限。连续时间结果属于额外诊断，官方口径结果仍需使用既定后处理。

按预设规则选12至20个验证集案例，包括成功、无重叠、中心正确但过宽、Top-1失败而Top-k成功，以及多次发生同一声音的查询。展示查询文本、全部真实区间和候选时间轴；不能只选支持假设的案例。有原始音频时再听取，缺少音频不会阻塞诊断。

产物：时间步长说明、舍入前后对照表、案例图。需要少量GPU推理，通常几分钟以内；案例分析约半天。

## 5. 条件实验：诊断之后选择一条主路线

D0至D4全部做完后写一页决策报告。以下A、B、C不要求全跑：选择一条主路线，最多增加一项必要消融。避免用大量试验筛选一个偶然高分。

### A：宽度校准（D1/D2支持宽度瓶颈时）

第一步A0：保持中心不变，测试固定宽度缩放w'=alpha*w，alpha预先限定为0.5、0.75、1.0、1.25。对所有候选使用同一规则，仍使用原分数排序。1.0为必须保留的对照，所有结果都报告。正式推理中不得读取真实目标时长；不能仅对“真值短于5秒”的查询缩放。

可能结果：短片段改善而长片段明显变差，说明统一缩放存在取舍；无明显改善则停止该路线；诊断替换改善很大但固定缩放无效，可能需要按可观测特征预测校准量，不能直接认为要继续加大缩放。

第二步A1（可选）：使用训练侧独立校准数据拟合简单校准器，输入仅含预测宽度、候选分数、可选文本/音频特征。先尝试少参数函数或小回归模型，不直接引入复杂网络。对零重叠候选需明确训练目标与过滤规则，多真值匹配规则保持固定。

必需对照：无校准、固定缩放、学习型校准；固定模型与校准器应分别保存。若需要80/20训练侧划分，校准结果只能与相同划分的未校准模型比较，再说明与原完整训练B2的差异。

预期：若两个seed短片段指标均改善且其他组损失可接受，可作为小型方法贡献；若只是缩短输出而IoU不升，说明缩短宽度不等于更好定位。

算力：A0主要CPU；A1可能需重训两个训练侧模型，T4并行200轮初步预算2至3小时，校准器开销很小。预算参考既有38秒/轮，需冒烟测试复核。

### B：候选重排（D3显示候选有明显余量时）

先做R0简单规则对照：利用预测分数、预测宽度等可观测量改变排序；包括不惩罚宽度的原始排序。禁止使用真实IoU、真值时长或oracle选中的候选作为测试时输入。

若规则改善支持继续做R1，可用训练侧独立校准预测训练一个小评分器，标签为候选对真值的质量，输入只含推理可得到的特征。使用按音频划分的校准数据，避免相同音频查询泄漏。这里使用R0/R1作为排序实验编号，避免与第一阶段基线B1混淆。

必需消融：原分数、仅宽度规则、仅原分数校准、小评分器。单调转换所有候选分数不会改变排序，不能当作有效重排；它可能影响mAP，需区分指标含义。

预期：若重排提高R1但宽度统计变化很大，这是选中了不同候选，不能称为同一候选边界被修正。若Top-k潜力很大而可学习排序不提升，要检查输入特征是否有足够区分信息。

算力：CPU或少量GPU；若使用独立训练侧校准方案，两个模型重训约2至3小时，后处理本身很快。

### C：训练损失干预（D2支持边界瓶颈且A/B不足时）

第一步C0只改一个因素：对短真实目标的span与GIoU训练损失施加温和权重。权重来源只能是CASTELLA训练标注，例如<5秒为2，其余为1，并在batch中按平均权重归一化，以降低总体梯度尺度改变带来的混淆。

需要先确认匈牙利匹配后的目标长度与回归损失逐目标计算方式；第一版保持匹配代价、分类损失和saliency损失不变。该方法在训练时读取真值时长合法，在推理时不得读取。保持B2预训练checkpoint、两个微调seed、学习率、训练轮数、batch和选点指标相同。

必需对照：原始损失（复用同配置B2）与加权回归损失。主实验只测试一个预先固定的权重；最多加一个权重=1的实现一致性检查，不进行大范围网格搜索。

若D2主要显示位置错误且D3候选不足，则不自动采用宽度校准或C0。先根据案例判断是否需要更好的查询相关时间打分/局部定位监督，另写方案后再实施。当前证据不足以指定网络改动，计划不把尚未确定的架构当作必跑实验。

预期：短片段指标在两个seed中一致提高，同时宽度或中心诊断改善，支持进一步验证；只有训练损失下降而验证定位无提升，判为无效；短片段提高但整体/长片段损失明显，报告性能取舍。

算力：两组T4并行微调200轮，预计2至3小时。修改后的单轮耗时与显存必须通过1至3轮冒烟测试确认。

| V重复与最终报告 | 选定方法后必做 | 最终配置、同seed基线 | 主表、分组表、限制 | 按分支决定 |

计划中的小时数为预算，不能保证运行时间。CPU分析优先在本机完成，云端只在推理或训练期间开机。先完成诊断，再根据结果决定需要启动哪项训练。

## 7. 什么结果算有效，什么时候停止

最低完成标准：D0至D4可以复现，给出位置、宽度、排序三类诊断和适用限制。即使没有有效新方法，也能形成诚实的分析型课程论文。

方法主指标预先定为验证集<5秒R1@0.7，短片段R1@0.5作为共同检查项；checkpoint仍沿用整体验证R1@0.7选择，避免通过改选点规则制造优势。若尝试另一选点规则，必须作为单独实验，让基线也使用同样规则。

建议的工程筛选门槛：两个seed短片段R1@0.7均不下降、均值至少提高1个百分点，短片段R1@0.5均值不下降，整体mAP均值下降不超过0.5个百分点。门槛是预先约定的实践判断，不是统计显著性标准；验证短片段组173条查询中，一个成功案例就约0.58个百分点，需要同时报告成功查询数。

若达到门槛，可增加seed=2025，对基线和方法都运行，再报告每个seed与均值。额外微调种子只评估固定预训练权重下的波动；完整流程的稳定性还需要重新预训练多个seed，当前算力预算不默认包含它。

使用按音频ID聚类的配对bootstrap报告R1差值的不确定性，同一音频的查询一起抽取。区间只反映评估样本波动，不能替代预训练或微调种子重复。只有两个seed时，图中seed范围不称为置信区间。

如果一条路线在两个seed上都没有方向一致的收益，或最多一项必要消融后仍未达工程门槛，则停止这一分支。不要因负结果无限增加参数、网络或数据集。每条方法可能失败的原因只能写成待验证解释。
